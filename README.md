XIAO RP2040 Macropad

A compact 9-key macropad with a rotary encoder, built around the Seeed Studio XIAO RP2040 and running CircuitPython. 
It comes with a custom PCB designed in KiCad and a snap-fit 3D-printed case that needs no screws.


Features
3×3 grid of MX-style mechanical switches
EC11 rotary encoder with push button
Seeed XIAO RP2040 with USB-C
Programmed in CircuitPython: just edit code.py, no compiling
Snap-fit case and knob, printable without screws

Bill of materials
1x	Seeed Studio XIAO RP2040
9x	MX-style mechanical switches
9x	SOD-123 diodes
1x	EC11 rotary encoder (D-shaft)
9x	MX-compatible keycaps
1x	3D-printed case (tray + lid) and knob

Ordering the PCB

Upload the Gerber files from pcb/production/ to a PCB manufacturer such as JLCPCB or PCBWay. 
The default options (2 layers, 1.6 mm thickness) work fine.
